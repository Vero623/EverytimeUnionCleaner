# EverytimeUnionCleaner
에브리타임 연합 게시판에 작성한 모든 글과 댓글을 지워줍니다.

에브리타임([everytime.kr](https://everytime.kr/))에서 **본인이 작성한 게시글과 댓글을 일괄적으로 삭제할 수 있도록 만든 Python GUI 도구**입니다.

Selenium을 이용해 사용자가 직접 로그인한 브라우저 세션에서 인증 정보를 획득한 후, 에브리타임의 서비스 요청을 이용하여 본인의 게시글과 댓글을 순차적으로 삭제합니다.

> ⚠️ **삭제된 게시글과 댓글은 복구할 수 없습니다. 실행 전에 반드시 삭제할 콘텐츠가 없는지 확인하세요.**

---

## 주요 기능

* **내 게시글 일괄 삭제**

* **내 댓글 일괄 삭제**

* **일시정지 / 재개**

* **작업 중지**

### 최신 버전

**Windows 사용자는 Python을 설치하지 않고 Releases에서 실행 파일을 다운로드하여 사용할 수 있습니다.**

[GitHub Releases에서 다운로드](https://github.com/Vero623/EverytimeUnionCleaner/releases)

## 요구 사항

### EXE 실행 파일을 사용하는 경우

GitHub Releases에서 제공되는 `.exe` 파일을 사용하는 경우 Python이나 별도의 Python 패키지를 설치할 필요가 없습니다.

다음 환경이 필요합니다.

* Windows
* 인터넷 연결
* 에브리타임 계정
* Chrome 브라우저

### 소스 코드로 실행하는 경우

소스 코드를 직접 실행하려면 다음 환경이 필요합니다.

* Python 3.x
* Selenium
* Requests
* Tkinter

필요한 패키지는 다음 명령으로 설치할 수 있습니다.

```bash
pip install -r requirements.txt
```

`tkinter`는 대부분의 Python 배포판에 기본적으로 포함되어 있습니다.

#### Linux

Ubuntu/Debian 계열에서는 다음 명령으로 설치할 수 있습니다.

```bash
sudo apt-get install python3-tk
```

#### macOS

Homebrew를 사용하는 경우:

```bash
brew install python-tk
```

#### Windows

공식 Python 설치 프로그램을 이용하면 일반적으로 `tkinter`가 함께 설치됩니다.

> 사용하는 Python 버전에 따라 패키지 호환성이 달라질 수 있으므로 문제가 발생할 경우 프로젝트의 `requirements.txt`와 Python 버전을 함께 확인하세요.

Python을 직접 설치하지 않고 실행 파일을 사용하려면 [Releases](https://github.com/Vero623/EverytimeUnionCleaner/releases)에서 최신 `.exe` 파일을 다운로드하여 실행하세요.

> 실행 파일은 소스 코드에 포함되어 있지 않으며 GitHub Releases에서 별도로 제공합니다.

```bash

cd EverytimeUnionCleaner
pip install -r requirements.txt
python main.py
```

## 사용 방법

### 1. 에브리타임 로그인

프로그램을 실행한 후 **`1. 에브리타임 로그인`** 버튼을 클릭합니다.

브라우저 창이 열리면 평소와 같은 방법으로 에브리타임에 로그인합니다.

로그인이 완료되면 프로그램이 삭제 작업에 필요한 인증 정보를 가져오고, 이후 삭제 관련 기능을 사용할 수 있습니다.

### 2. 내 글 모두 삭제

**`2. 내 글 모두 삭제`** 버튼을 클릭하면 본인이 작성한 게시글을 조회하여 순차적으로 삭제합니다.

### 3. 내 댓글 모두 삭제

**`3. 내 댓글 모두 삭제`** 버튼을 클릭하면 본인이 작성한 댓글을 조회하여 순차적으로 삭제합니다.

대댓글을 포함하며, **본인이 작성한 댓글만 삭제하도록 동작합니다.**

### 4. 일시정지 / 재개

작업 중 **`일시정지`** 버튼을 이용하여 작업을 잠시 중단할 수 있습니다.

다시 작업을 진행하려면 **`재개`** 기능을 사용합니다.

### 5. 작업 중지

삭제 작업을 더 이상 진행하지 않으려면 **`중지`** 버튼을 사용할 수 있습니다.

## ⚠️ 삭제 전 반드시 확인하세요

이 프로그램의 삭제 기능은 **되돌릴 수 없는 작업**입니다.

실행하기 전에 다음 사항을 확인하세요.

* 중요한 게시글이나 댓글이 없는지 확인
* 필요한 콘텐츠가 있다면 별도로 보관
* 삭제 대상이 본인이 의도한 범위인지 확인
* 대량 삭제를 실행하기 전에 프로그램의 동작을 충분히 확인

삭제된 콘텐츠의 복구 가능 여부는 에브리타임의 서비스 정책에 따르며, 프로그램에서는 삭제된 콘텐츠를 복구할 수 없습니다.

## 보안 및 개인정보

이 프로그램은 로그인 과정에서 획득한 **인증 정보(쿠키)**를 에브리타임 요청에 사용합니다.

인증 정보는 별도의 파일이나 데이터베이스에 저장하지 않고 **프로그램 실행 중 메모리상 변수로만 관리하며, 프로그램이 종료되면 함께 소멸합니다.**

인증 정보는 계정 접근에 사용될 수 있는 민감한 정보이므로 다음 사항에 주의하세요.

* 인증 쿠키를 다른 사람에게 공유하지 마세요.
* 인증 정보가 포함된 로그나 파일을 공개 저장소에 업로드하지 마세요.
* 프로그램의 소스 코드나 실행 환경에 인증 정보를 직접 입력하지 마세요.
* 프로그램 실행 중 인증 정보를 임의로 복사하거나 외부에 전달하지 마세요.

따라서 다음과 같은 상황이 발생할 수 있습니다.

* 에브리타임의 서비스 구조가 변경될 경우 프로그램이 정상적으로 작동하지 않을 수 있습니다.
* 서비스 측의 요청 제한이나 기타 제한으로 인해 작업이 중단될 수 있습니다.
* 대량의 콘텐츠를 짧은 시간에 삭제할 경우 예상하지 못한 제한이 발생할 가능성이 있습니다.
